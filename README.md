# QuestForge starter web app

## Run it now on a computer
Open `index.html` in Chrome. Most app features work locally. Installing as a PWA and offline service-worker caching require HTTPS (or localhost).

## Put it on your Android home screen
1. Upload the contents of this folder to a static HTTPS host. GitHub Pages is a free option.
2. Open the published `https://...` URL in Chrome on your Android phone.
3. Open Chrome's ⋮ menu and choose **Install app** or **Add to Home screen**.
4. Launch QuestForge from its icon.

## Features in this starter
- Responsive desktop/mobile interface with bottom mobile navigation
- Dashboard, XP, levels, hunter ranks, quests, daily planner
- Study subjects and topics, habit tracking, skill tree
- Weekly activity, local analytics, reflection notes
- Local browser saving, JSON export/import, reset
- PWA manifest, icons, service worker for offline app shell

## Important limitations
- This is a front-end prototype; there is no account system, cloud sync, MongoDB, Express API, or multi-device sync yet.
- Progress is saved in the browser's local storage on the device/browser you use.
- Back up regularly using Settings & Data → Export backup.
- To use across devices or let public users create accounts, the next step is a MERN backend and authentication.
